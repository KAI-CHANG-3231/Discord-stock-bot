# DCapp Stock

臺指選擇權三大法人多空未平倉、小台指散戶多空比儀表板與 Discord Bot。

## 快速啟動

雙擊或執行：

```text
DCapp_stock_open.bat
```

啟動後會開啟：

```text
http://127.0.0.1:8080
```

請保持啟動視窗開啟；按 `Ctrl+C` 可停止服務。

## Discord 設定

Discord Bot 設定集中在：

```text
discord_config.json
```

格式：

```json
{
  "DISCORD_BOT_TOKEN": "你的 Bot Token",
  "DISCORD_CHANNEL_IDS": [
    "第一個頻道 ID",
    "第二個頻道 ID"
  ],
  "DISCORD_SEND_AFTER_REFRESH": "1"
}
```

仍相容舊版單一頻道設定 `DISCORD_CHANNEL_ID`。如果同時存在 `DISCORD_CHANNEL_IDS` 與 `DISCORD_CHANNEL_ID`，系統會合併並自動去除重複頻道。

## 主要功能

- 每日台北時間 `16:20` 抓取期交所官方資料。
- 商品固定為臺指選擇權 `TXO`。
- 計算外資、投信、自營商的多方、空方、淨額。
- 以期交所 `MXF` 三大法人未平倉與 `MTX` 每日行情推導小台指散戶多空比。
- 產生「市場訊號」百分比、方向、信心、驅動因子與風險提示，讓資料變成可快速閱讀的每日判讀。
- 回算近 30 日同類市場訊號的隔日大盤表現，顯示平均隔日變化作為輔助參考。
- 觸發極端值提醒，例如外資合成金額劇烈變化、法人散戶背離、盤面平靜但籌碼移動。
- 網頁顯示最新摘要、圖表分頁、歷史表格。
- Discord 圖片使用「盤後市場快照」版型，包含市場訊號百分比、一句判讀、重點提醒、核心指標與 30 日方向趨勢。
- Discord 可傳送摘要與圖表，並支援 slash command：
  - `/stock_today`
  - `/stock_chart`
  - `/stock_refresh`

## 檔案用途

- `app.py`：主程式，負責資料抓取、計算、HTTP API、排程與 Discord Bot。
- `templates/index.html`：網頁介面模板。
- `DCapp_stock_open.bat`：唯一啟動檔，雙擊即可開啟專案。
- `discord_config.json`：Discord Bot token 與頻道設定。
- `discord_config.example.json`：Discord 多頻道設定範例，不放真實 token。
- `requirements.txt`：Python 套件清單。
- `data/latest.json`：最新抓取後的資料快取。
- `static/*.png`：自動產生的圖表圖片。

## 產品化方向

若要讓使用者願意付費，核心不只是資料本身，而是「幫使用者節省判讀時間」：

- 每日市場訊號：用 `0` 到 `1` 的方向值呈現，網頁以百分比顯示；`0%` 極度偏空、`50%` 中性、`100%` 極度偏多，並搭配方向標籤、信心與風險提示。
- 可追蹤的判讀依據：所有結論都連回外資合成部位金額、小台散戶多空比、大盤漲跌與前值比較。
- 訊號驗證：平均隔日變化與樣本數可作為輔助參考，避免只憑單日感覺判讀。
- 極端提醒：在 Discord 與網頁中主動標示值得注意的籌碼變化，降低漏看風險。
- Discord 即時分發：收盤後自動把摘要與圖表推送到社群，降低使用者每天打開網站的成本。
- 下一階段可加入：多週期勝率、會員分層、匯出 PDF 日報、盤後自動回測、付費訂閱驗證。

## 計算公式

### 臺指選擇權三大法人

- 多方口數 = 買權買方未平倉口數 + 賣權賣方未平倉口數
- 空方口數 = 賣權買方未平倉口數 + 買權賣方未平倉口數
- 淨額 = 多方口數 - 空方口數

### 小台指散戶多空比

- 小台全體未平倉量 = 期交所 `MTX` 各單式到期月份未沖銷契約量加總，排除跨月價差。
- 小台三大法人未平倉淨額 = 期交所 `MXF` 三大法人未平倉多空淨額加總。
- 小台散戶淨留倉 = `-1 * 小台三大法人未平倉淨額`
- 小台散戶多空比 = `小台散戶淨留倉 / 小台全體未平倉量 * 100`
- 小台散戶做多 = `小台全體未平倉量 - 小台三大法人多方未平倉量`
- 小台散戶做空 = `小台全體未平倉量 - 小台三大法人空方未平倉量`
